# Fomo Lens

Verified users receive free research access with no application daily request or credit quotas. Email verification, persistent sessions, owner-only usage reports, concurrency one, duplicate prevention and explicit uncertain-request recovery remain enforced. Public examples remain clearly synthetic; failed production requests never substitute examples.

The application supports profile, PnL, following, followers, wallets, reverse-wallet lookup, coverage and leaderboard research, plus pagination, comparison, shared selections and private history. Atomic UTC usage counting, reservations, settlement and unresolved-accounting retention remain in the existing schema.

GitHub-hosted CI verifies the lockfile on Node 24 with isolated PostgreSQL and desktop/mobile browser tests, builds without runtime keys and scans source/artifacts. Verified main artifacts deploy through pinned SSH with backup, atomic switching, readiness and rollback. Runtime keys remain outside releases and can be rotated without rebuilding.

Historical provider acceptance remains incomplete: 14 confirmed credits plus a preserved unresolved 100-credit reservation under the original acceptance-runner ceiling of 120. No further paid acceptance was run. This is not a public-launch billing gate. See [release verification](docs/release-verification.md) for exact evidence and deployed revisions.
